# About GoStudios Portable USB Stick

## About
GoStudios Portable USB Stick is a portable Android 16 environment that runs from a USB drive on any Windows PC.
It boots a Play Store-enabled Android 16 emulator and uses **GoUI 4.9** as the system UI / home launcher.
