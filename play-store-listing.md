## Full description
GoUI 4.9 is a custom Android launcher and system UI built for the GoStudios Portable USB Stick.
It features a GoStudios Account system, a Gaming Hub with GoStudios Picks and Web Apps (Xbox Cloud Gaming, PlayTree, GeForce NOW, Steam Link, YouTube, Discord), a Google Play Store tab, and paged Home Spots for your apps.

## Release notes (v4.9)
- GoStudios Account system (sign-in / create account)
- GoStudios Gaming Hub
- Google Play Store integration
- Multiple Home Spots (12 apps per spot)
- Rounded UI, Settings and About tabs
