About

A non-bootable portable Android 16 USB stick that runs Android in an emulator on any Windows PC. Plug it in and Android 16 (with GoUI 4.9 as the system UI) auto-opens in fullscreen; unplug and it auto-closes.

Features

Android 16

Play Store-enabled system image with Google Play Services.

GoUI 4.9

Custom system UI with account system, Gaming Hub, and Play Store tab.

Auto open/close

Watcher detects plug/unplug and launches or closes the session.

Fullscreen

Auto-maximizes and returns to desktop on exit.

USB Maker

GUI tool to create new sticks on any PC.

Gaming Hub

Xbox Cloud Gaming, PlayTree, GeForce NOW, Steam Link, YouTube, Discord.

Quick Start

  1. Format a USB as NTFS, label it "GoStudios Portable USB Stick".
  2. Run setup.ps1, then create-avd.ps1, then build-goui.ps1.
  3. (Optional) Run install-watcher.ps1 as Administrator for auto-open.
  4. Plug in and run launch.bat.
